# 一二布布角色状态与视觉反馈

> 状态：**planned** ｜版本：V0.1

## 用途

用角色贴纸提高亲和感，但不能遮挡主要文件操作，也不能用“开心表情”代替真实操作结果。

## 角色与状态

| 产品情境 | 视觉状态 | 规则 |
|---|---|---|
| Welcome / idle | 双角色欢迎图 | 大幅 Hero 只在欢迎/空态显示 |
| Search | 找文件表情 | 素材小型、不挡文本 |
| Planning | 思考/写字 GIF | 遵守减少动态效果设置 |
| Awaiting approval | 等待/期待 | 审批按钮和完整路径优先 |
| Executing | 工作中 | 长时间执行不增加复杂闪烁 |
| Completed | 开心/庆祝 | 仅实际全部成功时显示 |
| Failed/cancelled | 疑惑/中性 | 不误报成功、不用情绪代替错误说明 |

## 素材规则

- **使用可追溯原版一二布布 PNG/GIF**，不得通过 AI 重新描画角色五官。
- 角色与 UI 分层，透明素材独立引用；允许裁白边/压缩/等比缩放，不任意改变比例或表情。
- 需要保留来源、实际使用许可说明和分发记录；素材许可不随代码开源许可证自动授出。
- 原版高清资源未落盘时使用中性占位，绝不把低清参考图当成发布资产。

## 工程细则（待实现）
