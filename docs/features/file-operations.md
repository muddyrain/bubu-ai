# AI 文件整理

> 状态：**planned** ｜版本：V0.1

## 核心价值

自然语言告诉 AI 如何整理本地授权目录，然后**先预览全部操作、用户确认后才修改**。不是让模型执行任意脚本。

## V0.1 任务链路

`用户提出需求 → 模型转为分类规则 → Node.js 扫描直接子文件 → 生成不可变 FilePlan → 检查冲突 → 用户审批 → 逐项校验+移动 → 核对报告`。

## 范围与限制

- 仅处理一个授权文件夹的**直接子文件**，不递归移动子目录。
- 首版按文件扩展名分组（图片、文档、压缩包等）；分类实际由确定性程序完成。
- 不自动删除、覆盖、修改文件正文；不处理隐藏、特殊和符号链接文件；未匹配规则的文件不动。
- 目标目录必须属于当前读写授权范围；不同设备之间的移动等复杂情况可以暂时标记不支持。
- V0.1 对整份计划批准/拒绝，不提供尚未完成的逐行编辑；调整规则需生成新计划并重新审批。

## 审批与执行

完整列出 `源文件 → 目标文件`，处理计数、冲突及跳过原因；批准绑定 `planId / version / digest`，失效时重新审核。执行时二次核对源文件元信息、路径范围和目标冲突；不因按钮点过一次就忽略重放风险。取消阻止下一步，不对已经执行的操作作虚假回滚承诺。

## 结果与异常

成功/跳过/失败的计数来自本地工具；部分成功显示 `partially_completed`；源文件在审批之后被其他程序改动需跳过或失败；用户拒绝则零写入。

## 测试（待实现）

空目录、重复文件名、目标已存在、授权撤销、路径逃逸、审批后源变更、拒绝/取消、重复提交、部分成功、进程异常的可核对结果。
