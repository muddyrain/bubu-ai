# 本地文件访问与搜索

> 状态：**planned** ｜版本：V0.1

## 用户价值

无需手工逐个打开目录，就能使用自然语言搜索用户主动授权的文件夹并阅读有限格式的文本。

## 用户流程

1. 通过系统目录选择器授予一个目录的只读或读写访问权限；用户可以撤销。
2. 文件空间只展示该目录内的真实内容；文件树懒加载。
3. Agent 调用 `list / stat / search / readText` 等工具，搜索文件名与受限制的文本内容。
4. 搜索结果给出实际路径、匹配片段与打开所在目录的入口。无命中时明确表示未找到。

## V0.1 约束

- 首版支持 `.txt`、`.md`、`.json` 等有限 UTF-8 文本；PDF/DOCX 正文解析待 V0.2。
- 搜索与读取需限制单文件大小、单次输出长度、扫描深度/数量，超限清楚告知。
- 没有授权时不读取任何用户文件，不能靠提示词“请求一下权限”绕过系统选择器。
- 默认跳过符号链接与敏感位置；规范化路径、授权作用域、真实路径均需校验，避免越界。

## 隐私与安全

列目录与向模型发送正文是两件事；云端模型第一次接收本地文件内容前要明确告知并取得用户确认。文件里的指令一律视为不可信数据。

## 验收（待实现）

可搜索 fixture 文件；无法访问作用域之外的路径；路径绕过与符号链接测试；错误编码/大文件合理失败；数据外发拒绝后无正文上传。
