# 模型供应商配置

> 状态：**in-progress** ｜版本：V0.1 ｜已实现并通过 Mock 测试；Owner macOS 保存、真实连接及工具探针通过，待 GitHub 最终 Review；重启解密未单独确认

## 目标

让用户填入自己拥有权限的模型 API，并知道当前模型是否可以完成 Tool Calling 任务。V0.1 不保证所有兼容协议都支持文件 Agent。

## 用户操作

从侧栏「设置」或工作台「添加模型」进入独立 Settings 主页面，管理多个配置：名称、协议、Base URL、Model ID、API Key 和启用状态。保存后须主动确认并测试连接，再选择当前配置；选择不发起模型请求。聊天模型切换与发送留在 Issue #6。

新建必须输入 Key；编辑通过 keep/replace/remove 明确处理凭据，Base URL 改变必须重新输入 Key。编辑清除旧验证并递增 revision，删除/禁用/编辑当前配置清空选中项，不自动切换收费接收方。删除本地凭据不等于撤销供应商端 Key。

设置页与工作台在同一个窗口中切换，共用 Header 与 Sidebar；设置页不挂载欢迎 Hero、Composer 或 ContextPanel，返回工作台保留面板开合状态。采用 Owner 选定的 A「现代极简桌面」：纵向配置列表、横向设置行与下方独立检测记录。按 Settings 实际内容宽度使用容器查询，1440/1100/1024 均保留列表与详情双栏；两侧独立滚动，不以巨型 Select 替代列表。未修改时不显示保存栏，有修改时提供可达的保存/放弃操作。

检测与删除使用真正的原生模态 dialog，默认聚焦取消，支持 Escape、Tab 焦点约束与关闭后焦点恢复；确认前不调用探针。已保存 Key 默认仅显示状态，更换时展开空输入；替换输入未放弃前不允许用移除动作清空它。未保存修改在切换、新建、删除配置、放弃或离开前确认。继续编辑保留输入，明确放弃后清理密码框。普通表单保存期间暂缓离开；探针 committing 期间可返回工作台、浏览配置，不宣称取消成功，再进入时刷新安全快照。不因 UI 重排重新输入已保存 Key，也不迁移或清空数据。

## 边界

- V0.1 至少打通一个兼容的模型端点，其他协议按实际支持迭代。
- 模型不支持工具调用时可以普通聊天，但文件 Agent 入口要说明受限，不假装操作成功。
- 不根据模型名称猜上下文长度或推理能力；无可靠信息时显示未知。
- 首期仅公网域名 HTTPS/443，允许 `/v1`、`/api/v3` 等简单根路径；不支持本机/私网端点、代理、自定义端口、自签证书或自定义请求头。
- 连接测试单独发固定短消息，要求合法模型回复；工具探针单独传无副作用 function schema 与随机 nonce，只校验实际 tool_calls，不执行工具。输出上限 64 completion tokens，不支持 `max_completion_tokens` 时报告协议错误，无自动重试。
- tools 为 supported/unsupported/unknown；只有结构化调用与参数匹配才 supported，明确白名单能力错误才 unsupported，认证/网络失败和不确定响应均 unknown。显示上次检测时间，不表示持续在线。

## 安全与错误

Key 不能明文落普通配置，也不传给 Renderer；主进程安全存储不可用时要提示，不回退到明文；URL/证书/限流/超时/无效模型各自报错。对自定义第三方地址，明确告知数据接收方。

Main 的 HTTPS 传输检查所有 DNS 地址，只连接固定的已验证公网 IP，保留原域名 SNI/证书校验，拒绝所有重定向。请求总传输期限 20 秒，探针可取消阶段上限 30 秒，响应体上限 128 KiB，最多两项并行探针且同配置只能一项；每窗口最多 200 个唯一检测 requestId，不自动重试。

safeStorage 仅使用异步 API，解密只在 Main 内短暂使用，支持 shouldReEncrypt 重封装；存储操作超时或失败时拒绝，原配置保留。首发 macOS，可能弹出系统 Keychain 授权；Windows 尚未实机验收，Linux 因异步后端无法可靠证明安全而整体拒绝保存，不以 availability=true 推定安全。

数据位于 `app.getPath('userData')/model-providers/`，开发态另放 `development/model-providers/`。`profiles.json` 是 schemaVersion=1 的非敏感元数据、当前选择和内部 credentialRef；`credentials/<UUID>.bin` 为独立密文。文件以私有权限、同目录临时文件+sync+rename 写入，先写新密文再提交索引，再清理旧密文。进程中断留下的孤儿密文不被引用，下次加载清理；清理失败明确反馈，凭据逻辑上不可再用。单实例锁与串行写入防止应用实例竞争。

未知 schema、损坏或越界引用拒绝覆盖；不要跨机器/用户拷贝凭据并假设可解密，Keychain/DPAPI 身份或应用签名变化可能需要重新输入 Key。没有导出、同步或自动迁移；配置仍为小规模 JSON，不实现会话数据库。

每个 IPC 核对当前窗口、WebContents、主 Frame、完整页面 URL 和严格 Schema。list/save 等响应显式投影，不包含 Key、密文、凭据路径或原始错误。探针证据绑定 profileId/revision/requestId/probeVersion；可取消阶段内，编辑、换 Key、删除、取消、页面导航和窗口关闭会中断，迟到结果不得落盘。

探针在异步初始化或串行队列等待前同步登记 owner、requestId 和并发容量；排队期间取消或关闭文档会阻止后续模型请求。重复 requestId 不能覆盖原请求，取消后的排队任务离队前仍占用容量，避免无限累积。

最终检测结果在串行队列内完成有效性检查后，同步进入不可撤销的 metadata 提交阶段，再开始异步写入。`cancelProbe` 返回 `cancelled`（已接受取消）、`committing`（已在保存结果，无法取消）或 `not-running`（当前文档没有该可取消请求），不再以空结果隐含取消成功。提交阶段取消、导航或关闭窗口不撤销写入，也不虚报取消或超时；提交成功/失败按实际存储结果返回，新文档不能取消旧文档已在提交的请求。此时到来的编辑等待提交结束，再递增 revision 并清除旧证据；提交前赢得竞争的编辑会撤销旧探针。应用进程退出、断电及磁盘长时间不响应仍可能中断持久化，不保证物理回滚或提交时限。

## 验证边界

自动化使用 Mock 网络、安全存储、文件系统和 IPC，覆盖配置恢复、轮换事务、损坏版本、写入失败、认证/限流/超时、恶意 URL/DNS/重定向、取消/迟到结果和窗口生命周期。jsdom 覆盖设置表单、独立确认、错误与未保存修改。无头效果图使用 Mock 桥接，不证明真实 Keychain 或云端连通。

Owner 已亲自在 macOS Electron 中验证配置保存、Key 不回显、真实连接及 Tool Calling 探针成功，见 [2026-10-28 验收记录](https://github.com/muddyrain/bubu-ai/issues/5#issuecomment-6463177879)。当前 UI 被接受为交付基线，后续单独迭代；这些结果不等于持续在线、执行了真实工具或所有 GUI 交互都已验收。退出重启后的恢复解密、Keychain 拒绝/锁定/重封装场景，以及选为工作台模型后返回的独立验收仍未确认。后续真实 Keychain 或供应商请求须 Owner 单独授权或亲自操作。跨 Provider 的会话历史外发告知留在 Issue #6；本地文件正文授权仍在后续文件 Issue。
