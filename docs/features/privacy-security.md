# 隐私与权限

> 状态：**in-progress** ｜版本：V0.1 ｜模型凭据与网络限制已本地实现，文件权限仍 planned

## 用户看得见的原则

用户必须知道 AI 可以访问哪个目录、拥有只读还是读写权限、什么时候会修改文件、什么内容可能发往第三方模型。

## 最小安全规则

- 首次启动没有文件访问范围；每个目录必须经系统选择器显式授权，随时可撤销。
- 所有文件工具由 Electron 主进程校验权限，不使用 AI 提示词充当安全边界。
- 永远不默默删除、覆盖目标文件或读取凭据/密钥；对路径解析、软链接与执行时状态变化做防护。
- 本地文件正文若需发送云端模型，需明确告知接收方并授权；切换模型/跨轮继续对话不自动沿用对新接收方的授权。
- 执行日志默认最小化，不记完整敏感文件正文、API Key 或不必要的私人路径；开发调试数据也要脱敏。

## 用户可用控制（计划）

模型设置现已提供具名配置管理与独立检测确认，Key 不回显；仅向所确认供应商发送固定探针消息，保存本身不联网。传输仅 Main 侧公网 HTTPS/443，TLS、DNS 地址和重定向限制不可由 Renderer 放宽。密文在 OS 应用数据目录单独保存，安全存储失败不落明文，开发数据隔离；详见 [模型供应商](model-providers.md)。自动化全部使用 Mock；Owner 已亲自验证 macOS Electron 保存、Key 不回显、真实连接与工具探针成功。退出重启后的恢复解密及 Keychain 异常场景尚未单独确认，后续真实测试仍须单独授权。

授权目录与权限列表、撤销授权；写操作方案审查与拒绝；任务停止；查看操作状态和异常原因。

## 失败原则

信息不足、权限检查失败、审批过期或数据外发被拒绝时：**拒绝操作并向用户解释**。不做“方便使用”的自动放权或自动保存明文 Key。
