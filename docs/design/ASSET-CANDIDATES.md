## 具体提醒

1. 第三方 Sticker Maker 页面同时写了“Credits to 黄小B”和“these stickers are property of Fwooby”，说明该合集有上传者与原创作者两层信息，需要区分，不能依据标题自动把全部图片当作原作者素材包。
2. 不能仅根据网页预览推断透明背景或分辨率，必须下载并检查图像模式、alpha 通道、帧数、文件体积、GIF 背景色等参数。
3. 部分内容是有文字的表情包，适合作为参考但不适合直接贴在软件 Banner，不能把“原角色”与“背景/文字/贴纸装饰”混为一个层。
4. 用户说明作者支持二创且不损害 IP 形象；项目对外发布前仍建议保留授权来源及条件文本/截图，用于落实仓库分发与用户协议中的署名。
